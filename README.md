# GSB Bugfix Task
## 题面
渲染管线接上 MSAA 以后，边缘问题反而更多了。开着 MSAA，树叶的 alpha test 边缘还是一格一格，把采样数拉到八倍也一样，铁丝网和草叶最明显，跟没开一样；解析后的颜色边缘发黑，轮廓外侧多出一圈暗边，天空背景在角色轮廓上镶一圈灰边，背景色从采样点里渗进来；半透明玻璃边缘出现硬边，里面的场景被切成两半，折射也跟着错；HDR 颜色在 resolve 之后过曝，曝光值怎么调都压不下来，霓虹灯牌变成纯白色块，亮部糊成一片白；深度缓冲解析后精度掉了，远处山脊的描边一帧有一帧无；自定义 resolve 在 stencil 边界算错，多出一圈不属于角色的轮廓；VR 左右眼的采样数不一致，一边四倍一边两倍，清楚和糊对不上；MSAA 和后处理顺序反了，抗锯齿被后面的模糊吃掉；切换分辨率后采样数没重建，从全屏切窗口再切回来就花，窗口放大后边缘变成台阶；移动端按 tile 解析时读到相邻 tile 的样本，边缘出现色块；多重采样纹理被当普通纹理采样，颜色整体偏暗；关掉 MSAA 后旧的解析结果还残留一帧，切换场景时闪一下。msaa_resolve_mask.py 的 MsaaResolve 要校验采样数、格式和分辨率，不合法时抛 MsaaSetupError；解析权重按覆盖率、alpha 和深度计算，颜色在线性空间混合，HDR 亮度不能先钳位，不能把背景色渗进边缘；深度解析取保守值，模板和覆盖掩码一起解析；分辨率、采样数、MSAA 模式或设备变化时重建目标，解析通道有单帧预算，超了降采样但不能改覆盖规则。图形组拿两台机器、三种分辨率各截了边角。两台机器、三种分辨率我都试过，边缘问题跟着分辨率变。
