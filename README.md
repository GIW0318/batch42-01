# GSB Bugfix Task
## 题面
手柄震动改成时间线混合以后，手感变得很怪。两个效果同时播放，低频和高频叠在一个马达上，直接削顶，变成持续的嗡嗡声；低优先级的脚步震动把高优先级的爆炸打断，爆炸只剩前半段；效果播完以后马达还在转，要等下一次震动才停；蓝牙手柄延迟大，射击游戏的后坐力总是慢半拍，画面已经落地了震动才来；同一个效果在采样率不同的手柄上时长不一样，有的长有的短；打开暂停菜单时震动继续，回来手都麻了；从手柄切到另一款设备，左右马达的通道映射反了；长时间连续震动以后手柄发热，系统自动降幅，游戏没有感知；自适应扳机的阻力曲线在段与段之间跳变，扣扳机像卡了一下；同一帧内重复提交同一个效果，震动强度翻倍；游戏退出时没有发停止指令，手柄一直震到断电；效果时间线里两个片段重叠，混合权重没有归一，强度超过最大值。haptic_timeline_mixer.py 的 HapticTimeline 要把效果定义、通道混合和设备输出分开，每个效果带优先级、时长和通道曲线；同一效果编号重复播放按请求编号幂等，不能叠加两次，高优先级效果可以打断低优先级，但低优先级恢复时要从剩余时间继续；时间线按采样点推进，不同设备按统一时间基换算，采样率不同时重采样，设备断开、切换或游戏退出时立即发送停止指令并清空队列；非法强度、负时长或通道数不匹配抛 HapticConfigError，单帧混合超出预算时降低更新率但不能改变总时长。测试组把三款手柄摆在桌上逐个过。三款手柄我都接上试过，上面每种现象都能复现。

## 运行方式

```bash
python -m pytest tests -q
```
