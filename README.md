# GSB Bugfix Task
## 题面
2D地图编辑器更新后，关卡组集体罢工。两块地图交界处画草地，autotile只更新左边，右边还是旧图；撤销一次只回退一格，连续画的一笔要按十几次；图集版本更新后旧地图瓦片索引整体错位，打开旧关卡像换了一张地图，河流变成山；同一张地图在两台机器上打开，autotile结果不一样；大图每画一格全图重算，撤销一次也要等好几秒，卡到没法用；碰撞层和视觉层用了不同瓦片，寻路也跟着穿墙，玩家能走进水里；调色板替换只换视觉层，导出的截图和游戏里不一致，小地图还是旧颜色；保存时只存变更格，换台机器打开就变样，重新加载后边缘规则没重算；多层地图按图层号排遮挡，改成 Y 轴排序又轮到别的层错，角色被树挡住脸；导入旧版本地图，未知瓦片被静默替换成空白；autotile规则里斜角邻居没参与，斜坡边缘出现直角缺口，美术只能手动补；瓦片是二十四像素而地图块按三十二像素切，块边界永远对不齐。tilemap_autotile_rule.py 的 TilemapAutotileRule 管邻接匹配、块边界、撤销和导入。autotile要按四邻和八邻规则在块边界继续匹配，接缝两侧结果必须一致，斜角规则也要算进去；撤销重做以一笔为单位，撤销栈要有上限，重做后地图要和撤销前逐格一致；未知瓦片ID导入必须整张拒绝并报 UnsupportedTileError，不能填空，也不能只导入一半；编辑操作串行提交，批量填充也要作为一个事务，同一格并发写入只有一个生效。地图保存要带瓦片集版本，读档时版本不符就走迁移，迁移失败要保留原文件而不是覆盖，不能默默错位。关卡组现在不敢动地图，先把邻接规则、撤销和版本迁移做稳。

## 运行方式
```bash
python -m pytest tests -q
```
