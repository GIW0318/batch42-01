# GSB Bugfix Task
## 题面
新地图上线后，地形颜色问题被美术和玩家一起骂。四层草地叠在一起总权重超过一，远处地表发白，走近又正常；两块地形块接缝处出现一条硬边，草和石头各占一半；高度混合开着，岩石边缘多出一圈半透明光晕，远看像贴了一圈发光边；纹理数组超过十六层后，第十七层采样到第一层的图；相机拉远，地形LOD切换时整体颜色跳一下，阴影边缘也跟着闪；陡坡雪线按世界高度算，南北坡的雪线高度不一样；贴花压在地形上，地形LOD一变贴花就浮空；半精度浮点在权重接近零时变成负数，局部地表发黑；地形块流式加载时权重图还没到，先渲染成纯色；移动端每像素采样十二次，帧率掉到二十，发热之后还会降频；同一块地形在编辑器里正常，打包后权重图被压成八位，过渡带出现明显色阶，回滚到编辑器又看不出来；地形挖洞后权重采样越界，洞边缘拉出一圈拉伸纹理，洞口的碰撞体却没跟着更新。terrain_splat_blend.py 的 TerrainSplatBlend 管权重归一、图层采样、高度混合和LOD。每像素四层权重归一后必须为一，四层之外的影响按最大权重合并，不能直接丢掉；纹理数组越界必须回退到默认层，不能读到另外一层，洞边缘的采样要钳制到最近有效纹素；LOD切换时同一世界坐标的混合结果要连续，颜色跳变不能超过阈值，接缝两侧的法线和高度也要连续；单帧地形着色有固定预算，超了按距离降采样并输出降级标记。接缝两侧的权重图要能互查，接缝处的高度和法线也要能对上，别让一块地形改了另一块还是旧样子。美术在编辑器里看是好的，打包就变样，先把权重和 LOD 接缝对齐。

## 运行方式
```bash
python -m pytest tests -q
```
