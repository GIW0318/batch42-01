# GSB Bugfix Task
## 题面
游戏换成 HDR 管线以后，调色和曝光天天被美术投诉。从室内走到室外，穿过门洞的那两秒，自动曝光要两秒才缓过来，夜里进洞又慢半拍，中间一段全白；高光部分直接死白，金属反射的高光边也保不住，灯泡周围的颜色一圈一圈往外溢，云层细节全丢，颜色还往青色偏；LUT 在图集边缘采样到相邻的格子，天空和地面各出现一条色带；色调映射把 UI 也一起处理了，白色按钮变成灰色；同一份素材在 PC 和主机上亮度差一截，同一台显示器切 HDR 模式也差，HDR 和 SDR 两套监视器对不上，gamma 明显不一致；夜景暗部被拉亮以后噪点全出来了，像蒙了一层沙；自动曝光按屏幕中心点测光，角色站在阴影里时背景全白，逆光时人脸全黑；白平衡和分级 LUT 的顺序反了，暖色场景被校成冷色；HDR 转 SDR 以后红色偏橙，队服颜色不对；切换场景时 LUT 没有重建，过场和战斗共用一张旧表，上一关的色调残留；半透明特效叠加时每层都做一次 tonemap，粒子重叠处直接烧白；曝光补偿滑到负值时画面直接黑屏，滑块拉回来也不恢复。tone_curve_grade.py 的 ToneGrade 要把曝光、色调映射和分级 LUT 拆成三步，顺序固定；曝光按时间平滑，室内外切换先测光再过渡，过场结束要复位到当前场景的测光值；LUT 采样前做边界钳位，三线性插值不能跨格；UI 和文字在 tonemap 之后单独合成，同一输入在同一平台上的输出必须逐像素一致，LUT 尺寸为零或曝光时间为负时抛 GradeConfigError。美术在三个场景各截了十组对比图，调色台那边已经停了两天。这三条路线我各拍了一组对比图，现在没有一组能看。
