# GSB Bugfix Task
## 题面
开放世界换成分级阴影以后，画面一动阴影就抖，雪原和雨林共用一套参数却表现不一样。相机往前走，树影边缘像有蚂蚁在爬，停下来才稳；两级阴影的交界处有一条明显的亮线，远处那级一加载就更明显；相机只旋转不移动，阴影也跟着在地面上游动；最远一级的阴影分辨率不够，整片山坡糊成一团；角色脚下的接触阴影时有时无，近处反而没有影子；半透明的窗帘投出一整块全黑阴影；阴影视锥和相机视锥没有对齐，屏幕边缘一圈完全没有阴影；太阳角度稍微一变，所有阴影同时跳一格；深度偏移调大以后，影子从脚底脱离，调小又出现条纹；级联切换的瞬间，远处的建筑突然出现或消失；两个动态光源共用一张阴影图集，后渲染的把前面的覆盖掉；角色在阴影边界走动时，半个身子在影子里半个在阳光下，边界是一条锯齿。shadow_cascade_stabilize.py 的 CascadeStabilize 要把级联划分、光源矩阵和阴影图集分开算，级联边界按相机视锥的切分比例确定，切换时只允许整纹素跳动，相机平移不能出现半纹素漂移，也不能因为帧率变化改变切分位置；级联之间按世界空间距离淡入淡出，接缝两侧的阴影强度必须连续，过渡带宽度按世界空间单位配置，不能随分辨率缩放；非法级联数、零尺寸阴影图或退化光源方向抛 ShadowSetupError，错误信息里要带级联编号和配置项名称；多光源按编号分配固定图集区域，单帧更新有预算，超了降频但不能改投影矩阵。三级阴影在三条天气路线下都能复现，先把级联边界和纹素对齐固定住。

## 运行方式
```bash
python -m pytest tests -q
```
