# GSB Bugfix Task
## 题面
容器平台换运行时以后，宿主机上开始出现莫名其妙的目录，安全审计说隔离被破坏了。容器里的挂载传播到宿主机，宿主机能看到容器临时目录；卸载时目标 busy，错误被吞掉，挂载残留在表里；并发创建容器时挂载表互相串，一个容器的卷出现在另一个容器里；运行时重启后挂载状态没恢复，容器根文件系统错乱；只读挂载被 remount 成读写，没报错；配置的 shared、slave、private 传播类型没生效，全按默认走；挂载源路径带符号链接，实际挂到了宿主机另一个目录；挂载点越积越多，超过内核上限后新容器起不来；容器退出后挂载没清理，一天泄漏几千条；同一源目录两个容器用了不同选项，选项互相污染；用户命名空间映射和挂载属主对不上，容器内写文件变成 nobody；中间某一步失败后前面挂好的没回滚。mount_namespace_propagation.py 的 MountPropagationGuard 要把挂载当成事务处理。硬门禁：挂载和卸载必须原子，任一步失败全部回滚；容器退出必须清理全部挂载；只读挂载被 remount 成读写必须返回 EPERM；并发创建不得互相看到对方的挂载。test_mount_namespace_propagation.py 的十五条检查在预发环境跑了一下午，没有一条能过。

## 运行方式
```bash
python -m pytest tests -q
```
