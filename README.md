# GSB Bugfix Task
## 题面
手柄改键功能上线后，玩家把设置页骂上热搜。手柄热插拔之后键位回到默认，自定义配置全丢；同一个按键绑了两个动作，按下去两个一起触发；导入别人的配置，手柄型号不同，扳机键变成数字键；键盘和手柄同时操作，最后输入的设备抢走提示图标，动作却没生效；组合键在快速连按时只识别单键；死区保存后重启变回零，手柄放桌上角色自己转圈，摇杆漂移角色自己走；云同步把两台机器的配置合并，冲突时也没有提示，重复绑定越积越多；某个游戏单独覆盖了键位，退出游戏后全局配置也被改，删掉覆盖项也回不到全局；辅助功能里的长按和连发设置，重连手柄后失效，重启客户端才恢复；配置文件没有版本号，旧客户端导入新格式直接清空；手柄电量低时输入延迟变大，组合键判定窗口没考虑，频繁误触；同一个手柄在蓝牙和有线下被识别成两个设备，配置各存一份。input_remap_profile.py 的 InputRemapProfile 管绑定、死区、组合键、设备切换和同步。同一物理输入同一时刻只能触发一个动作，组合键优先级高于单键，按下时间差超过窗口就按单键处理，冲突绑定必须拒绝并返回 BindingConflict；热插拔后要按设备GUID恢复对应配置，GUID变化时要提示重新绑定，不能静默套用默认配置；云同步合并必须幂等，重复同步不能产生重复绑定；配置文件版本不兼容必须整体拒绝，不能只导入一半。设备切换要保留每种设备各自的最近一次配置，配置切换要立即生效，不能等下一次按键，别让键盘和手柄互相覆盖。设置页的投诉还在涨，先把绑定冲突、热插拔和云同步收敛。

## 运行方式
```bash
python -m pytest tests -q
```
