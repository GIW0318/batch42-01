# GSB Bugfix Task
## 题面
角色控制器换到新物理后端以后，手感全毁了。站在二十度的斜坡上不动，人会自己往下滑，松开摇杆还缓慢下滑，停不住；上台阶时人在边缘弹一下，连续上三级会被弹回原地，镜头跟着抖；站上移动平台，平台一转向角色就被甩下去，平台往前走，角色留在原地，下一帧又被硬拉回去，看起来像穿模；贴着墙连续按跳，能一格一格蹬到屋顶；头顶撞到天花板后，向上的速度没有清零，落下来之前还会再弹一次；同一段跳跃在六十帧和三十帧下高度差半个身位；蹲着钻进矮洞后松开蹲键，人卡在里面起不来；地面检测的射线只打静态层，站到木箱和升降台上都判定悬空；冲刺的位移直接改坐标，薄墙一穿就过；从高处落地前按跳跃没有输入缓冲，手感很粘；斜坡转到平地时速度方向突变，人会横着滑出去；被两个碰撞体夹在中间，角色直接被弹飞到地图外。motor_slope_contact.py 的 SlopeContact 要把输入采样、固定步进和接触求解分开，逻辑步长固定，输入按帧累积后只在步进时消费，渲染帧只做插值，同一段跳跃在三十、六十和一百二十帧下高度一致；移动平台用上一帧到这一帧的位移差带着角色走，角色在平台局部空间里的位置保持；地面法线按接触点取，非法坡度和退化法线抛 ContactSolveError；同一帧内重复的跳跃按下只认一次，落地缓冲最多一百毫秒，最终位置必须在所有接触面外侧。关卡组把三种帧率的录像并排放在一起。我给三台不同帧率的机器都装了同一段跳台，落地高度每次都不一样。

## 运行方式
```bash
python -m pytest tests -q
```
