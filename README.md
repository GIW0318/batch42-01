# GSB Bugfix Task
## 题面
屏幕空间接触阴影上线后，角色脚底反而更假了。相机一转，脚下的阴影方向跟着转，蹲下时又反过来，角色转身暗部也跟着甩，像有个手电筒在晃；栏杆这种细长物体完全没有接触阴影，地面上一点痕迹都没有，桌腿和电线也投不出来，地面还是平的；接触阴影穿过墙投到隔壁房间，门外的人影投在室内地板上，墙面上出现人形黑块；远处物体的接触阴影拉成一条长线，越远越粗，一直拖到画面边缘；带孔的铁丝网投出一整块实心黑斑，洞眼全被抹平；接触阴影和级联阴影重叠的地方黑成一片，边缘还有硬边；镜头横移时接触阴影一闪一闪，静止时才稳；光源压到地平线附近时接触阴影直接消失，黎明和黄昏最明显，角色像浮在地上；深度不连续的门框处漏光，地面亮出一条缝；移动端每像素步进次数太多，开阴影后帧率掉一半；VR 左右眼的接触阴影位置不一致，看久了恶心；角色跳起来以后脚下的接触阴影还留在地上。contact_shadow_trace.py 的 ContactShadowTrace 要在视图空间沿光线步进，步进距离和厚度都设上限，参数非法时抛 ContactShadowError；采样只读当前帧深度，深度和法线来自同一套缓冲，遇到深度断层就停止，不能穿到墙后；遮蔽量按距离、厚度和光线夹角淡出，抖动序列固定并可复现，相机移动时不能逐帧换噪声；每帧步进总量有上限，顶到上限先降分辨率再降步数，VR 两眼共用同一套采样参数。场景组在台阶、栏杆和墙角各摆了一组道具。我把角色放在台阶、栏杆和墙角各拍了一组，漏光和断影都能看到。

## 运行方式

```bash
python -m pytest tests -q
```
