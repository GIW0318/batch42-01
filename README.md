# GSB Bugfix Task
## 题面
战斗混音加了自动闪避之后，语音和音效全乱套。Boss战音乐一响，队友语音被压得听不见，战斗结束也不恢复；两个闪避源同时触发，增益叠成负值，整轨静音；快速切场景时压缩器释放太慢，新场景前两秒没有声音；静音某个总线后闪避还在算，取消静音音量就不对了；语音聊天和游戏音效共用一条总线，队友一说话脚步全没；存档里的音量设置重启后回到默认，只有主音量保留；过场动画的自动化曲线和实时闪避打架，音量忽大忽小，混音师只能手动压；三十二个音源一起触发侧链，CPU占用飙到四成，音频线程开始掉帧；换耳机后声道映射没更新，环绕声测试片段全错位，左声道跑到中置；淡出过程中关游戏，下次启动那条总线还停在淡出状态，手动改配置文件才恢复；闪避触发时语音总线也被压，队友以为麦克风坏了，队伍语音只能另开软件；暂停菜单打开后闪避状态冻结，关掉菜单音乐一直压着不起来。audio_ducking_mixer.py 的 AudioDuckingMixer 管总线、侧链、优先级、快照和恢复。闪避增益要按优先级取最大值，不能连乘，优先级相同的源按触发时间取最新，任何组合都不能低于静音阈值；总线静音和独奏要立即生效且不改底层增益，取消后恢复原值；重启后所有总线增益和静音状态从配置恢复，恢复完成前不能播放，避免先响一下再变音量；每帧混音预算固定，超了按优先级丢低优先级音源并报告。切换输出设备时要重建声道映射，设备热插拔也要走同一条路径，不能把旧布局直接套上去。混音师已经被闪避搞怕了，先把优先级和总线状态恢复改对。

## 运行方式
```bash
python -m pytest tests -q
```
