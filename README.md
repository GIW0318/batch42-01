# GSB Bugfix Task
## 题面
桌面云把系统总线开放给第三方应用后，普通账号改掉了网络配置，还顺手读了别的会话的通知。策略规则按文件顺序第一条命中就返回，deny 写在 allow 后面永远轮不到；send_destination 只比对总线名不比对唯一名，应用换一个名字就绕过去；eavesdrop 默认允许，任何应用都能窃听会话总线上的消息；方法调用的 path、interface、member 只要有一项为空就按通配处理，授权范围大得离谱；用户组按名称比较，域用户和本地同名组被混为一谈；策略文件重载不是原子操作，半套旧规则和半套新规则同时生效；策略缓存只按用户名做键，切换用户后仍然命中上一个人的结果；拒绝时返回的错误名不区分权限不存在和被拒绝；同一条消息命中多个策略文件时取了并集而不是交集；服务激活发生在策略加载之前，先启动后补规则；日志只写允许，拒绝一条都不记。dbus_policy_evaluator.py 的 DbusPolicyEvaluator 要先归一总线名和唯一名再匹配，deny 优先于 allow，路径三段必须精确命中，策略重载用版本号做原子切换，缓存随版本失效，拒绝和允许都写审计并带上命中的规则，重载期间的匹配结果保持一致。test_dbus_policy_evaluator.py 十五条断言在桌面云镜像里跑，结果全失败。

## 运行方式
```bash
python -m pytest tests -q
```
