# GSB Bugfix Task
## 题面
宠物繁育上线两周，交易行里的蛋价已经乱了。两只宠物放进繁育屋，取回时其中一只还在冷却，另一只凭空多出一条冷却；双胞胎特性触发后只生成一颗蛋，界面却扣了两次材料；近亲惩罚没生效，同一血脉连着三代还能出隐藏特性；繁育过程中把宠物挂到交易行卖掉，蛋孵出来归买家，冷却却留在卖家身上；服务器重启后正在孵化的蛋从列表里消失，用掉的加速道具只退了一半；孵化队列满了还能开始繁育，蛋进了个看不见的槽位；隐藏特性概率按客户端上报的幸运值算，改包就能必出；同一颗蛋在两个角色背包里都能看到，谁先点谁得到；赛季更新后旧蛋的特质表变了，孵出来的宠物带着不存在的技能；批量孵化十颗只出了一颗，其余显示已孵化但背包里没有；两只宠物同时放进两个繁育屋，冷却只扣了一次，两边都开始孵；孵化加速道具在最后十秒使用，剩余时间反而变长。pet_breeding_genetics.py 的 PetBreedingGenetics 管配对、扣冷却、孵化、认领和恢复。一颗蛋只能归一个角色，并发认领只成功一次，第二次返回 egg_claimed；开始繁育要原子扣父母冷却和材料，父母被交易或放生时整单失败并退回材料；重启后按蛋快照恢复剩余时间和特质，不能重新随机，也不能把已孵化的蛋变回孵化中；近亲系数到阈值必须拒绝，抛 InbreedingBlocked，不能偷偷降低概率，同一对父母重复配对的冷却要按服务器时间算。孵化结果要能从父母、蛋ID和繁育批次追溯到同一条记录，客服查复制蛋时能对上。蛋和冷却的账已经乱成一锅粥，先把配对、孵化、认领三处对齐。

## 运行方式
```bash
python -m pytest tests -q
```
