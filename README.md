# GSB Bugfix Task
## 题面
我们做了个游戏内调音器，吉他手一用就说指针在跳舞。低音 E 弦明明在八十二赫兹，界面显示成一百六十四赫兹的高八度，调低音谱表也救不回来；拨弦瞬间指针先跳到高音再掉回来，衰减段又慢慢升上去，根本看不清；房间里有人说话，指针跟着人声乱摆；偏差超过五十音分才显示，轻微跑音完全看不出来；同一段录音在四十四点一千赫兹和四万八千赫兹下算出不同的音高，换一台声卡又是第三个值；蓝牙耳机延迟大，显示的音总是慢半拍；和弦模式只显示最低的那根弦，扫和弦时其他弦没反应；停止拨弦以后指针停在最后一个音高不动，不归零；音频分析放在主线程，界面每隔几秒卡一下；切换录音设备后 A4 基准从四百四十变成四百四十二，校准设置没生效；环境噪音大时把静音段判成低音，指针一直抖；采样窗口太短，低音弦还没完成一个周期就开始算。pitch_track_tuner.py 的 PitchTuner 要把音频回调、分析窗口和界面更新分开，回调里只做拷贝，分析放在独立线程；音高检测先做基频候选，再用谐波一致性排除八度错误，候选置信度低于阈值时不更新显示；分析窗口按采样率换算成固定时长，加窗和补零规则一致，四十四点一和四十八千赫兹的结果必须在允许误差内一致；静音和噪声段要回到未检测状态，A4 校准值参与所有音分计算，设备打开失败或采样率不支持抛 TunerDeviceError。乐手把三把琴都接上试了一遍。这个调音器我给三个乐手试过，每个人都指出了上面至少四条。

