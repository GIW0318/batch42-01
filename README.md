# GSB Bugfix Task
## 题面
国际服改成按本地时间重置日常以后，客服工单翻了三倍。美国玩家跨过夏令时那天，日常提前一小时重置，周常也跟着提前，奖励领了两次；同一账号在两个时区登录，两个时区各自重置，任务进度被清了两遍；零点整在线的人，任务计数清零了但已接任务还挂在列表里；周常和日常共用同一个重置锁，日常重置把周常也清了；重置任务跑到一半进程重启，一半玩家清了，另一半没清；两个分片同时扫描到期账号，锁没有生效，同一批人收到两封重置邮件；维护延迟到凌晨两点，重置仍按原定时间跑，维护结束后玩家看到的是空任务；跨服角色在源服重置了，目标服还是旧进度；手动补发重置补偿时没有去重，有人领了四份；重置时间配置成负数或超过二十四小时也能保存；玩家在重置前最后一秒交任务，服务端按重置后判定，奖励没了；排行榜的每日成绩在重置后没有归档，历史数据被覆盖。daily_reset_scheduler.py 的 DailyReset 要把账号时区、重置周期和已执行批次分开存，每个周期按账号时区生成唯一批次号，同一账号同一批次只能执行一次；重置和任务提交撞在一起时，按任务完成时间归属周期，不能看处理时间；服务重启后从批次表继续未完成的账号，跨服角色按全局角色编号只重置一次；时区或周期配置非法抛 ResetConfigError，重置完成后先归档排行榜再清当期数据。运营把三个时区的重置日志并排打印出来。三个时区的测试账号我都跑过，基本每种都能撞出来。

