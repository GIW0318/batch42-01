# GSB Bugfix Task
## 题面
剪辑工具上线片段导出以后，导出的片子总是差几帧。设了从三分十秒到三分四十秒，成片开头多出两帧黑，结尾少一帧，关键帧对齐后还是差，客户对不上字幕；切点落在 B 帧中间，解码器往前找参考帧，实际画面偏了三帧，音频却按切点切；音频比视频早四十毫秒，口型对不上；手机竖拍的素材导出后方向转了九十度，人横着躺；可变帧率素材按平均帧率算时长，成片比原片短两秒，拖到尾帧还会黑一下；关键帧离切点很远，导出前把整段都解了一遍，十分钟的片子跑了二十分钟；导出中途磁盘满，工具提示成功，文件只有一半；同一个片段导出两次，MD5 不一样，文件头里写进了导出时刻；字幕在切点后被截断，最后一句只剩半行；导出范围超出素材时长时没有报错，直接补黑帧；多轨素材的音频采样率和视频帧率不匹配，导出后音画不同步。clip_export_range.py 的 ClipRange 要把入点、出点、关键帧索引和音视频轨道分开处理，切点按帧号而不是秒数表示；导出前先找不晚于入点的关键帧，从那里解码到出点，再裁掉多余帧；音频按采样点定位，声道映射和采样格式一起转换，补偿编码 priming，保证和视频帧对齐，旋转元数据在导出后保留；同一份输入和参数导出两次必须逐字节一致，入点大于出点、超出素材时长或帧率非法抛 ClipRangeError，导出中断要留下临时文件和断点，重跑从断点继续。客户把五台手机的原片和成片并排看。五种手机素材我各导了一遍，每种都能对上至少两条。

## 运行方式
```bash
python -m pytest tests -q
```
