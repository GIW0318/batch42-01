# GSB Bugfix Task
## 题面
家园系统开放租赁后，矛盾全堆到客服这边。两个人同时往同一格放家具，最后两件叠在一起，碰撞体积也变成双份；房主关了访客权限，访客还能用上次的传送点直接进屋；租约到期前十分钟续费，钱扣了但到期时间没变，第二天房子照样被回收；搬家时家具返还邮件超过附件上限，剩下的几件直接消失，玩家背包和邮箱都找不到；家具旋转后占格没重算，墙角能卡进墙里；服务器重启后刚摆好的家具回到旧位置，可已经消耗掉的那件还留在背包里；室友同时拖动同一件家具，一件不见了另一件变成两件；导入房屋模板时把别人的家具ID一起带进来，摆出来显示是自己的；租金按本地时间扣，跨时区玩家被提前一天赶出去；房主离线时访客改了公共区布置，房主上线发现权限设置根本没生效；家具在收纳箱和屋里同时出现，拆掉一件两边都少一件；租约还剩三天时被系统判成过期，后台查到期时间又是对的。housing_plot_lease.py 的 HousingPlotLease 管放置、授权、续租、搬离和恢复。同一格并发放置只能成功一个，另一个返回 slot_occupied，失败不能扣家具也不能留下看不见的占位；搬离必须原子，房屋状态、家具归属和返还邮件要么全成要么全不变；重启后未完成的搬迁要从日志接着做，邮件、房屋和收纳箱三处都不能出现同一件家具；权限变更要立即生效，旧会话再进门必须被拒绝。租约过期回收前要先落一条可回查的审计，记录回收时的租约版本和操作人，别让玩家问起来什么都查不到。我留了搬家前后的背包截图和邮件记录，按原子搬迁的口径收口就行。
