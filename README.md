# GSB Bugfix Task
## 题面
分支对话上线以后，主线任务开始出现走不通的存档。玩家在选项界面存档再读，对话从第一句重来，前面选的支线全没了；选项条件读的是接任务前的任务状态，已经完成的任务还能再选一次；两个分支同时满足条件时，系统按节点编号的字典序选了一个，剧情直接跳到没写过的结局；分支里改过的阵营变量退出对话就丢，下一个 NPC 完全不知道玩家选过什么；跳过语音只跳音频，字幕还停在上一条，口型和文本对不上；本地化缺行时直接把 key 名显示给玩家，句子中间夹着 dialog_042；对话中途 NPC 被击杀，对话框还在，点继续能一直说到结局；自动播放和手动点击同时推进，一次跳过两句，关键选项被默认选中；回退到上一个选项时，已经发出去的奖励没有回收，玩家可以反复刷；分支合并后临时变量作用域错，A 分支的变量污染了 B 分支；语音文件缺失时对话卡住，没有任何提示；同一个 NPC 被两个玩家同时对话，双方共享同一份节点状态，选项互相覆盖。dialog_branch_state.py 的 DialogBranch 要把节点、条件和变量作用域做成按访问序号推进的状态机，同一个选项编号重复提交只推进一次；存档快照要包含当前节点、变量表、已访问节点和奖励领取记录，读档后从原节点继续；条件评估只能读同一份任务状态快照，分支变量在合并点显式导出，不能靠全局变量串；非法节点、跳转目标不存在或条件表达式错误抛 DialogGraphError，奖励发放和节点推进在同一个事务里。玩家把存档发过来。这条主线我走了四个分支，每种都能卡住。

## 运行方式
```bash
python -m pytest tests -q
```
