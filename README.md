# GSB Bugfix Task
## 题面
排位选人阶段最近每十局就有一局出问题。双方同时锁定同一个英雄，两边界面都显示选中，进游戏一方变成随机英雄；ban阶段最后一秒提交，服务器已经切到pick，ban被吞了但计时还在走；有人秒退，其他人回到大厅，队列里却还留着这局的五个坑；重连回选人界面，倒计时显示零却还能操作，最后一秒选人失败；换英雄时对方已经锁定，交换请求一直挂着，倒计时结束也不清理，开局用的还是原来的英雄；观战端看到的pick顺序和实际不一致，导播只能按自己的界面猜，解说连着报错英雄；同一玩家开两个窗口能同时锁两个英雄；版本更新后新增英雄在老客户端显示为空，选人界面直接卡死，客户端也没有降级提示；选人超时自动选英雄，结果选到了已经被ban的那个，自动选择还会覆盖玩家已经点下的预选；重赛投票和投降同时触发，整局直接消失；选人时换设备重连，英雄池被重置，已经ban的英雄又能选；双方同时申请交换英雄，系统把两个请求都执行了，阵容里出现重复英雄。ranked_draft_pick.py 的 RankedDraftPick 管禁选顺序、计时、交换、重连和开局。每个英雄在同一局只能被选一次，重复选择返回 champion_taken；阶段推进只认服务端时钟，暂停和恢复也要走同一个时钟，客户端改时间不能影响结果；秒退后该局所有席位要原子释放，重复释放不能把容量减成负数；重连必须恢复到当前阶段和剩余秒数，不能退回上一个阶段。选人结果落库后再开局，落库失败要退回选人阶段，不能带着空阵容开局，重试也不能重复锁英雄。排位每十局炸一局，先把禁选阶段和重连快照稳住。

## 运行方式
```bash
python -m pytest tests -q
```
