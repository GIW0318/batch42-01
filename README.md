# GSB Bugfix Task
## 题面
巡逻队在新开的雪原图上集体犯病，走两步就卡一下。拐角处单位先切角撞进墙里，半个身子卡在石缝里，再被物理推回来，来回三次才继续走；目标点落在岩石里时整队停在原地，状态仍显示移动中；动态门关上以后路径还从门里穿过去，人被门夹住掉血，门再打开也不会重新寻路；窄走廊里两个单位互相让路，位置每帧抖一下；传送门把队伍送到另一块区域，他们还在沿着旧路径往回走；跳台链接的方向填反了，单位走到边缘又跳回原层；局部避障一推就把人推出导航网格，直接掉进河里；异步重建导航网格的时候查询读到半成品，路径穿过刚砌好的墙，重建完成后旧查询还返回上一版的多边形；多个单位共用同一个路径对象，一个人改目标全队跟着改道；寻路失败返回空路径，AI 静默站着，日志里什么也没有；路径点索引在转身时回退一格，动画来回抽搐。navmesh_corridor_follow.py 里的 CorridorFollow 要把查询、跟随和重规划拆开，路径必须带网格版本号，查询、跟随和重规划读同一份版本，旧版本当场作废，单位位置和路径点索引必须始终落在有效多边形上；同一帧内的重规划请求按单位编号去重，每帧最多处理八个，超出的排队而不是丢请求；非法起点或终点要抛 NavMeshQueryError 并带格子坐标；进程重启后加载的网格要能接着走，不能从头找路。地图组现在每次改地形都要重启两次服务，不然巡逻队还是按旧网格走。这几种巡逻路线我各录了一段，眼下没有一条能从头走到尾。

```bash
python -m pytest tests -q
```
