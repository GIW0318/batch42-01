# GSB Bugfix Task
## 题面
射击游戏换了新的贴花系统，画面问题一堆。弹孔叠在血迹上，后放的被先放的盖住；贴花投在斜面边缘被拉成一条，法线混合后高光位置全错；图集相邻格子的颜色渗到贴花边缘，出现彩色描边；同一面墙超过三十二个贴花，最早的突然消失而不是淡出，玩家以为被人擦掉了；深度偏移太小会和墙面闪烁，不同显卡上表现还不一样，调大又浮在墙前；移动端半精度UV在远处抖动，静止镜头也在抖，贴花边缘一直跳像素；角色走过血迹，贴花跟着角色走，应该留在地上；贴花实例批次被打断，每贴一个就一次draw call，帧率掉一半；背面剔除把地板贴花剔掉，俯视视角直接看不到弹孔，从上往下看什么都没有；场景切换后旧贴花残留，新关卡墙上还有上一关的弹孔，要重启渲染器才干净；贴花落在角色骨骼上时跟着动画拉伸，应该留在地面；同一贴花被两个系统各提交一次，透明度叠成两倍。decal_projection_stack.py 的 DecalProjectionStack 管排序、投影、图集采样和上限回收。贴花按图层和创建序号稳定排序，同一帧内新增的按提交序号排，不能按指针地址，同样的输入渲染两次顺序必须一致；超过上限要按最旧优先淡出，不能硬消失，淡出期间仍要参与深度测试；图集采样必须限制在格子内，边界不能取到邻格颜色，mip链也要按格子生成；切场景要清空贴花池，不能跨场景残留。贴花的世界坐标和法线要跟宿主表面一起更新，宿主物体销毁时贴花要一起回收，别让它在斜坡上飘着。训练场的弹孔已经打成一片，先把排序、图集边界和回收上限一起收掉。

## 运行方式

```bash
python -m pytest tests -q
```
