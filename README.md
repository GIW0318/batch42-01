# GSB Bugfix Task
## 题面
移动端接入开放平台以后，安全评审在授权码换令牌这段挑出一串问题。挑战算法不传就被当成明文模式，等于没做校验；校验串的长度和字符集完全没限制，一个字符也能过；同一个授权码并发兑换两次，两边都拿到了访问令牌；校验失败之后授权码没有作废，攻击者可以接着试；公共客户端没有强制校验，拦住回调就能换令牌；回调地址尾斜杠差一个字符，校验时过时不过；授权码只绑了应用编号没绑回调地址，换个地址也能兑；授权码给了半小时有效期还能反复使用；并发续期时轮换记录丢失，旧续期凭证被拒，整条令牌链断掉；兑换时授权范围被悄悄放大；错误响应把校验串比对细节写进日志；授权服务重启后授权码状态全丢，用户只能重新授权。oauth_pkce_verifier.py 的 GrantExchangeGate 要把授权码、应用、回调地址和校验串绑成一次性的记录。四条门禁：同一授权码并发兑换只允许一个成功，另一个回 400 和 code_reused；校验失败必须回 400 和 bad_verifier 并把授权码作废；公共客户端不做校验直接拒绝；续期轮换必须原子，旧凭证再次出现要撤销整条令牌链。test_oauth_pkce_verifier.py 的十五条用例现在逐条都失败，兑换和续期两条链路都没通。

## 运行方式
```bash
python -m pytest tests -q
```
