# GSB Bugfix Task
## 题面
宠物跟随和指令这块，最近投诉特别集中。点了跟随，宠物卡在石头后面原地跑，主人走远后直接消失又出现在副本门口；攻击指令下达后目标死了，宠物转头打旁边的中立怪，引了一群；主人上坐骑，宠物还在地上追，追不上就瞬移穿墙进战场；宠物被眩晕时收到新指令，醒来先执行旧指令再执行新的；两名玩家几乎同时驯服同一只稀有怪，双方都拿到宠物；宠物死亡后尸体还在攻击，伤害算在主人头上；副本切换后宠物留在旧副本，旧副本里还能看到它站在原地，召唤出来带着旧副本的buff；宠物背包里的东西解散时消失，重新召唤又出现两份；挂机时宠物自动拾取把任务物品捡走，任务物品进了宠物背包还绑定了，任务卡住；服务器重启后宠物状态回到十分钟前，刚学的技能没了；宠物在主人死亡后仍留在原地，主人复活又召唤出一只，旧的那只还能被攻击；两只宠物同名，指令队列按名字匹配，结果下错目标，改名后旧指令还会跟过来。companion_ai_command.py 的 CompanionAiCommand 管指令队列、跟随、攻击、召回和跨场景迁移。同一只野外生物只能被一个玩家驯服，并发驯服第二次返回 already_tamed；宠物指令按序号执行，序号在同一主人名下全局递增，换宠物也不能回退，旧序号指令到达必须丢弃；跨场景必须跟主人同事务迁移，迁移失败要回滚到原场景，不能两个场景各留一只；重启后宠物位置、技能和背包从快照恢复，不能复制背包物品。宠物死亡要立即清空指令队列，复活后从空闲状态重新接指令，不能续上死前的攻击目标。宠物跟丢和双份驯服的工单堆了一摞，先把指令序号和跨场景迁移理顺。

## 运行方式
```bash
python -m pytest tests -q
```
