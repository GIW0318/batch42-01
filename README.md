# GSB Bugfix Task
## 题面
新资料片的增益系统一上线，团队副本里就开始出现各种怪事。同一个奶骑的祝福刷了三次，层数一直是第一层的时间，图标却显示三层，没有真正叠上去；两个不同来源的同名减益被当成同一个，后上的把先上的顶掉；驱散技能按增益和减益分类，结果把诅咒当成增益驱掉了；层数到期时只掉剩余时间，层数还在，属性加成一直挂着；打开暂停菜单时冷却和持续时间继续走，回来 buff 全没了；角色死亡后光环还在加属性，复活时属性直接翻倍；急速属性改变 tick 间隔后，最后一跳直接被吞掉，持续伤害少跳了一整次；两个光环在同一帧到期，回调顺序每次不一样，触发的套装效果有时生效有时不生效；断线重连后所有增益的剩余时间归零，但层数还在；免疫期间上 buff 被吞掉，材料却扣了；光环数量到上限后，第三十三个直接覆盖第一个，没有提示；跨地图传送时光环被清空，副本门口重新加一遍又叠了两层。aura_stack_scheduler.py 的 AuraScheduler 要把光环定义、实例和 tick 队列分开，实例带唯一编号、来源、层数和到期时刻，同一实例的重复施加按事件编号幂等，刷新和叠层按配置区分；持续时间用逻辑时钟计算，暂停和过场都走同一个时钟，重连时从快照恢复剩余毫秒；tick 顺序按到期时刻和实例编号排，死亡、免疫和驱散走同一条移除链路，属性和层数一起回退；未知光环编号或层数超限抛 AuraStateError。团长把战斗日志导出来对着 buff 列表看。团长让我在木桩前站了半小时，每换一次装备光环就多一层。

