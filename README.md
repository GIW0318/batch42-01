# GSB Bugfix Task
## 题面
塔防新关卡上线后，波次节奏完全不受控。玩家点暂停去接电话，回来一解除，三波怪同时从同一个出生点挤出来，直接卡成幻灯片；二倍速模式下刷怪间隔还是按真实时间算，切回一倍速又补一批，怪与怪之间空出一大段；上一波还剩两只没清，下一波倒计时已经走完，界面显示第二十波但场上只有十八波的怪；Boss 波和普通波刷在同一帧，两个模型重叠，Boss 被卡在出生点里出不来；中途存档再读档，波次从第一波重新开始，已经拿到的奖励又能再领一次；漏怪计数在怪物被击杀后还加一，结算显示漏了三十只；多路径地图只从第一条路出兵，换路标记形同虚设，另外两条路永远是空的；波次通关奖励在重连后重复发放，邮件里躺着两份；客户端预测击杀，怪还没死就提前刷下一波，服务端随后又刷一遍；刷怪没有单帧预算，一帧生成两千个对象，主线程卡死；同一波在两个分线各刷一份，玩家换线后看到双倍怪。wave_spawn_timeline.py 的 WaveTimeline 要把波次定义、刷怪队列和结算分开，波次编号加赛季编号做幂等键，同一波重复触发只执行一次；暂停时逻辑时钟冻结，倍速只改推进步长，恢复后从冻结的那一毫秒继续，不能补刷；读档要从最近的波次检查点恢复，已刷出的怪和已领奖励都要还原；单帧生成数量有上限，刷怪总数、存活数、击杀数和漏怪数必须满足守恒关系，波次配置非法时抛 WaveConfigError。玩家在论坛贴了二十波的时间轴截图。测试服那张图我连打了三晚，波次一到二十就全乱。

