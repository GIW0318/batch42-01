# GSB Bugfix Task
## 题面
领地战改成五秒一跳之后，每周结算都被玩家拿录像打脸。两个阵营同时站在旗点里，进度条来回跳，最后两边都弹出占领成功；占领完积分每秒在涨，可界面显示的归属和实际加分的阵营是反的；战场分了三条线，A线打下的点B线也跟着变色，守军凭空出现在另一条线；服务器卡了十几秒，恢复后一次性补算，积分瞬间涨一大截，排名直接翻盘；停战协议生效那一秒还有人在交火，双方都拿到了击杀分；增援点数显示为零还能继续复活，只是界面数字不动；玩家中途退出，贡献仍按全程算，挂机也能拿满奖励；占领事件因为重发被处理两次，结算邮件发了两封；维护重启后旗点全部回到中立，打了四十分钟的成果没了；老版本客户端看到的地图边界和新版不一致，站在界外也能占点；同一账号两个角色在同一阵营，贡献被算了两遍，结算直接多一份奖励；结算前一刻转阵营，旧阵营的积分还留在榜上。territory_war_tick.py 的 TerritoryWarTick 负责占点、按跳推进、停战、结算和恢复。同一个旗点同一时刻只能有一个归属，争夺期间进度必须归零重算，两边各自累计的旧进度要一起清掉；停机重启后要按最后快照恢复归属、进度和正在争夺的那一格，剩余增援也要对上，不能重置成中立；占领结算按据点和回合号幂等，重复上报只记一次；奖励只能发一份，断线重连不能补领第二份。跨线同步只同步归属结果，不能把另一条线的守军和增援一起搬过来。每周结算都被玩家拿录像对，先把归属和积分算成同一份结果。

## 运行方式
```bash
python -m pytest tests -q
```
