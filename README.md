# GSB Bugfix Task
## 题面
卡通渲染改版以后，角色描边在各种距离下都不对。站远了描边细得看不见，模型缩小到半屏时几乎没了，十米内又粗成一条黑边；角色跑到场景边缘，描边被视锥裁掉一半，直接消失；头发和裙摆的内部褶皱也描了一圈，看起来像线稿没擦干净；描边穿过墙体，隔两层楼也能看到，隔着墙能看到角色的轮廓；VR 模式下左右眼的描边偏移不一致，看久了头晕；描边受场景光照影响，背光面直接变成黑块，亮处变成白色；两个角色重叠时，描边互相穿插，后画的描边盖住前面角色的脸；法线平滑以后，硬边模型的转角变成圆弧，描边找不到边，机械关节全糊；4K 分辨率下描边比 1080p 细一半，美术要的是等宽；透明材质的描边画在不透明层上，排序一换就变，裙纱边缘出现实线；相机近裁剪面切进角色时，描边整圈消失，描边被切掉一半；角色被其他物体遮挡一半时，露出的描边断成几截。toon_rim_outline.py 的 ToonOutline 要把几何描边和屏幕空间边缘分开，线宽按屏幕像素定义，缩放和超宽屏都按同一基准换算；描边通道用独立的深度和法线，后处理不能改它的覆盖，内部边缘按法线夹角和深度差判定，平滑法线要保留原始硬边标记；描边在遮挡关系上跟随角色，不能穿墙，VR 下左右眼用同一套线宽和偏移参数；非法线宽、零分辨率或缺失法线图抛 OutlineSetupError，每帧描边通道超出耗时预算时降低采样但不能改线宽。美术在近景、远景和过场各挑了三张图。这几个视角我都截了图，问题一眼就能看出来。

