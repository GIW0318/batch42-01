# GSB Bugfix Task
## 题面
角色换装加了长发之后，近景截图里全是穿模。快速转身，头发直接插进后脑，停下来也不恢复；风里抖动幅度跟帧率有关，三十帧和六十帧像两个效果；近景发丝碰撞体只包住头骨，发梢整片穿过肩膀；角色传送后头发被拉成一条直线，镜头拉近能看到发丝一根根绷直，要等好几秒才回弹；LOD切到低模时发丝穿插头皮，阴影里更明显，远看像秃了一块；同一簇头发被两个风力源重复积分，整头飘到天上；透明发丝按对象中心排序，同一簇头发内部也会前后翻转，前后层次全乱；半精度下重力累积出NaN，头发整片消失；二十个角色同屏，头发模拟占满主线程，帧时间翻倍，关掉头发模拟才恢复；保存外观后重新加载，发丝初始姿态和保存时不一样；头发在低帧率下直接穿过肩膀，高帧率又正常，录屏回放里特别明显；同一角色换发型后旧发丝的碰撞缓存没清，新发型跟着旧发型抖。hair_strand_sim.py 的 HairStrandSim 管积分、碰撞、LOD和重置。模拟要按固定子步长推进，累加器要限制最大补帧数，卡顿后不能一次补几十步，三十、六十、一百二十帧下同一时刻的形态必须一致；发丝与头部碰撞后不能穿透，超过允许深度要回弹，低帧率也不能漏检；传送或切场景要重置历史位置，不能把上一张地图的位移带过来；每帧模拟预算固定，超了只能降远处角色，主角头发不能降级。保存外观时把初始姿态一起存下来，读档后第一帧不能出现从原点飞过来的动画，也不能把上一套发型的姿态套过来。近景截图一放大全是穿模，先把固定步长和碰撞缓存改对。
