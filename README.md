# GSB Bugfix Task
## 题面
镜面和水面的平面反射上线后，画面里的倒影全在乱飘。相机贴近水面时倒影上下颠倒，跳进水里再出来又正过来，天空跑到脚底；反射相机没有裁剪到水面以下，连水底的沉船和鱼都拍进去；角色站在镜面上，倒影里的角色偏移半米，脚对不上；斜着看镜子时倒影被拉长，蹲下看又压扁，比例完全不对；反射纹理分辨率和屏幕不匹配，窗口拉伸后边缘像糊了一层；两面镜子共用一张反射图，走廊里三面镜子互相打架，后渲染的把前面的倒影覆盖掉；倒影里没有粒子和飘带，主画面有烟但镜子里干净得像没打过；相机潜到水面以下，反射整个消失，只剩一片黑；反射里再反射，递归渲染把帧率砍半；反射相机的近裁剪面切掉角色脚部，倒影从脚踝开始；水面波浪法线扰动以后，反射坐标没有跟着偏，倒影钉在原地，船开过去也不动；切场景后旧反射图残留，新场景的地板映出上一关的树。planar_reflection_clip.py 的 PlanarReflection 要按反射平面构造镜像矩阵和斜裁剪面，相机在平面下方时直接禁用反射；每个平面各持一张渲染目标，窗口尺寸变化时按比例重建，不能和别的镜子共用；反射通道按层掩码只画参与反射的物体，静态和动态物体分开剔除，粒子按配置单独开关，递归反射最多一层；非法平面法线、零尺寸目标或相机参数退化抛 ReflectionSetupError，单帧反射超出预算时降低分辨率但保持矩阵一致。场景组把水面、镜面和湿地面各拍了一组。水面、镜面和湿地面我都试过，反射没有一次对得上。

## 运行方式

```bash
python -m pytest tests -q
```
