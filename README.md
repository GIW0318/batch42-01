# GSB Bugfix Task
## 题面
聚光灯换成图案投影以后，墙上的光斑开始串门。三盏灯共用一张 cookie 图集，图集页一换就全乱，四盏以上就开始互相串，左边灯的树叶图案跑到右边灯上；灯旋转角度后投影方向不跟着转，灯一摇头光斑还留在原处；cookie 边缘出现一圈黑边，放大看是图集相邻格的图案；灯离墙远了光斑不变大，换了聚光角度或范围也不跟着变，近了也不变小；cookie 图按 sRGB 采样却当线性用，透明边缘还会出现黑圈，图案整体发灰；动态切换 cookie 时闪一帧上一张图；点光源硬套聚光灯 cookie，投影在球面上裂成两半；512 的图在远处锯齿明显，换 1K 又吃显存；关掉灯以后墙上的光斑还留着，切场景也不清，远处的光斑还会变形，要等下一次刷新才消失；多线程更新图集时两个灯抢同一个槽位，图案混在一起；cookie 动画按渲染帧推进，掉帧时直接跳帧，灯按固定频率更新，两者越走越偏；烘焙的静态 cookie 和实时 cookie 混用，亮度差一截。light_cookie_atlas.py 的 CookieAtlas 要把图集分配、投影矩阵和动画帧分开，每个灯持固定槽位，槽位按灯编号分配且重复请求返回原槽位；投影矩阵要包含灯的朝向、视场角、宽高比和近远裁剪面，贴在斜面上也要跟着斜，灯旋转或换图案时整矩阵重算；cookie 只做一次 sRGB 到线性的转换，mip 链按同一规则生成，动画帧按时间取整，不能按渲染帧累加；槽位耗尽、图案尺寸不符、灯编号非法或动画帧越界抛 CookieAtlasError，关灯立即释放槽位，图集更新有单帧预算。灯光组在训练场摆了六盏灯逐盏对。训练场里我换了六盏灯和四张图案，串图基本每盏都有。

## 运行方式
```bash
python -m pytest tests -q
```
