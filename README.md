# GSB Bugfix Task
## 题面
邮件附件到期这块最近出了好几起丢东西的投诉。玩家在到期前点领取，界面一直转圈，等邮件过期了东西也没了；同一封邮件在两个客户端同时点，两件附件都进了背包；背包只剩一格，邮件里三件东西只到了一件，另外两件却显示已领取；退回给发件人时对方已经删号，邮件卡在系统里，把队列占满；邮件被删掉后附件没回收，过一阵又被另一个玩家领走；跨服邮寄的附件在目标服版本里不存在，领取后变成一封空邮件；维护重启后已经领过的邮件又变回未领取；批量领取一百封在第九十封时连接断开，前面领到的回滚了，后面没领的也被标成已读；到期时间按客户端时间显示，改系统时间能多留一天；客服补发的邮件和原邮件用了同一个ID，客户端只显示一封；同一封邮件先点退回又点领取，两边都执行，附件进了背包还退给了发件人；附件里有件限时物品，过期后邮件还在但物品已失效，领取直接报错卡住。mailbox_attachment_expiry.py 的 MailboxAttachmentExpiry 负责领取、过期、退回和清扫。领取动作按邮件编号做成幂等，两个客户端同时点同一封邮件，背包里只能多出一份，后到的请求返回 already_received；过期和领取要互斥，要么整封领走要么整封退回，退回失败要把邮件恢复原状，不能只走一半；重启后未完成的领取按事务日志回滚或续做，邮件状态、已读标记和背包必须一致；背包容量不够时整封不领，抛 InventoryFullError，不许部分领取。过期清扫要按服务端时间，不能信客户端，扫掉的邮件要保留可恢复的短期副本。这几起丢件我都有工单号，先把领取和过期做成互斥，再谈补偿。
