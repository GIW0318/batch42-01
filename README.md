# GSB Bugfix Task
## 题面
植被远景换impostor之后，树林看着像纸片。树从八方向换成十六方向，中间角度出现重影；远景树比近景亮一截，雾里特别明显，调了曝光也压不下去；impostor边缘一圈黑边，放大看是图集相邻帧渗色；风吹动画只作用在近景模型，远处的树像塑料，切到impostor瞬间静止；实例颜色乘了两次，同一片树林深浅不一，美术改一次颜色要重导两次；法线烘成固定朝上，远景树受光完全没有体积，背光面跟受光面一个颜色；LOD切换距离处两棵树同时出现，重叠一帧，玩家截图里像两棵树叠在一起；烘焙时相机近裁剪面把树冠切掉，图集顶部缺一块，重新烘焙也没提示；图集mip没留padding，远处树冠糊成方块，风一吹整片糊；一万棵草每棵一个quad，顶点数直接爆掉，显存也跟着超；impostor在阴影里还按烘焙亮度显示，夜里整片林子发亮，晚上像自发光；相机从下往上看树冠只剩一个薄片，方向图集没覆盖俯仰角。impostor_billboard_bake.py 的 ImpostorBillboardBake 管方向烘焙、图集布局、法线和LOD切换。impostor和近景模型在切换距离的颜色与轮廓误差要低于阈值，切换不能跳变，俯仰方向也要有对应帧；图集每格必须留保护边，mip采样不能取到邻帧，远景颜色要跟近景在同一光照下对齐；实例颜色只能乘一次，同一实例渲染两次结果一致；渲染预算固定，超了先降远处密度再合并批次，不能直接不画。烘焙结果要带方向索引，方向帧之间要按相机方位和俯仰双线性插值，运行时要能按相机方向稳定插值，别在两个角度之间闪。远景树林在雾里特别假，先把方向图集和切换距离调成一致。

## 运行方式

```bash
python -m pytest tests -q
```
