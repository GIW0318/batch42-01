# GSB Bugfix Task
## 题面
动作游戏换了新的拖尾系统以后，刀光像坏掉的彩带。快速连斩时拖尾中间断成两截，第三段直接不见，慢动作时又叠成一坨；角色用位移技能瞬移，拖尾横穿整个屏幕，还会拐一个直角，像一条黑线；拖尾自交的地方发黑，重叠三角形没有处理；低帧率下拖尾只有两三段，高帧率又密得看不清，弧线变成折线；UV 沿着长度拉伸，纹理被拉成条纹；两把武器共用同一个材质实例，改一把的颜色另一把也跟着变；拖尾寿命结束后顶点没有释放，切场景也不回收，打十分钟内存涨了两百兆；相机移动时拖尾边缘抖动，像没有对齐像素；透明排序把拖尾排在角色前面，刀光盖住了脸；暂停菜单打开时拖尾还在生成，回来堆了一大团；拖尾起点没有跟随骨骼，角色转身时刀光从背后长出来；同一帧内多次触发拖尾，采样点时间戳重复，生成零面积三角形。trail_ribbon_mesh.py 的 TrailRibbon 要把采样点、段索引和顶点池分开，每个采样点带时间戳和骨骼矩阵；采样点按时间严格递增，跨帧采样要插值到同一时间基，重复时间戳只保留最后一个，段数超过上限时从最旧的一段回收，不能产生零面积三角形；顶点池按帧复用，容量按最大段数预分配，寿命结束后立即归还，透明混合按深度排序，不能盖住主体；时间戳回退、骨骼缺失或段数配置为负抛 TrailError，暂停时停止采样，恢复后从当前骨骼位置重新开始。特效组拿三套连招逐帧看了回放。三套连招各打五十遍，断线和叠片都能稳定复现。

## 运行方式
```bash
python -m pytest tests -q
```
