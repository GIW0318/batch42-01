# GSB Bugfix Task
## 题面
拍照模式上线后，玩家拍出来的图和预览完全两回事。进入拍照模式世界没有暂停，NPC 还在走，飞鸟和云也在动，构图对了按快门时人已经走开；联机队友看到角色突然定住，技能冷却还在转，问是不是卡了；退出拍照模式后角色位置回到进入前，副本进度却停在进入那一刻，刚捡的材料也消失了；滤镜只作用在 UI 上，场景颜色一点没变；高分辨率截图边缘被裁掉一圈，和预览取景框对不上；隐藏 UI 后准星和血条还在截图里；相机能穿墙拍到未加载的区域，还能钻到地板下面，画面一片灰；拍照时被怪物攻击，队友在语音里喊也听不见，血掉了但画面没有任何反馈；连续拍十张以后显存不释放，重启游戏才回来，帧率一路往下掉；照片的元数据丢失，画廊缩略图也是黑的，拍摄地点和时间全是默认值；队友进入拍照模式后，队伍标记从小地图上消失；退出拍照模式时天气和时间被重置，拍的黄昏变成正午。photo_mode_sandbox.py 的 PhotoModeSandbox 要把进入、暂停、拍摄和退出做成原子状态机，进入时冻结本地世界并记录角色位置、天气、已拾取列表和正在播放的过场，退出时原样恢复；拍摄用离屏目标，预览和成片共用同一套取景、滤镜和隐藏层，分辨率切换要重建目标；相机按已加载几何做碰撞，非法视场角或负分辨率抛 PhotoModeError；照片连同元数据持久化，进程重启后还能查到，拍摄期间其他玩家看到的状态由服务端统一裁决。测试组拿主城和副本各录了十段。我在主城和副本各试了十几次，问题每次都能撞上。

## 运行方式
```bash
python -m pytest tests -q
```
