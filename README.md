# GSB Bugfix Task
## 题面
客服系统最近连着出了两起账号被盗，查下来都跟找回密码有关。重置链接用过一次还能再用；密码改完之后旧会话和自动登录凭证还在，别人照样能进；用户连点两次发送，后发的链接让先发的失效，但两封邮件都发出去了；链接里明文放了用户编号又没签名，改一位就能重置别人密码；邮箱大小写和别名处理不一致，响应时间差出几十毫秒，能枚举账号；链接有效期给了七天；重置成功只撤了当前会话，其他设备没动；频率限制按 IP 算，换代理就能无限发；已注销用户还能发起重置；链接比对用普通字符串比较，时序侧信道能逐位猜；邮件服务超时后链接已经落库，用户收到的是无效地址；管理员重置通道跳过了审计；重置 token 在库里明文存储，库被读走就能批量重置；同一账号短时间多次请求，旧链接没有全部作废；邮件链接域名没有和环境绑定，测试环境链接能打到生产；管理员重置没有二次确认，误操作直接踢掉全公司账号；成功审计只写结果，没有记录来源地址和旧会话数量。password_reset_token_gate.py 的 ResetTokenGate 要把链接生命周期和会话撤销做成一个事务。硬要求：同一链接只能用一次，第二次返回 reused；改密后链接与其他会话必须原子撤销；邮件发送失败必须回滚链接写入；账号不存在与存在时响应必须一致。test_password_reset_token_gate.py 的十五条检查今天上午跑了两遍，两遍都停在同一条失败上。

## 运行方式
```bash
python -m pytest tests -q
```
