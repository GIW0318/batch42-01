# GSB Bugfix Task
## 题面
肉鸽模式的每日挑战被玩家研究出花来了。同一颗种子重开游戏后生成的房间顺序不一样；在宝箱前退出重进，宝箱刷新，同一件装备能反复刷；双人联机时主机和客机的掉落不一致，客机捡到的东西主机看不见；第五层崩溃重进回到第三层，路上用掉的钥匙没退；每日挑战种子按本地日期算，改个时区能打两次；版本更新后旧存档的敌人表缺失，进层直接黑屏；复活道具在同一帧被两个队友同时使用，消耗了两份只复活一次；回放用同一颗种子但帧率不同，随机数消耗次数不一样，结果分叉；中途加入的队友拿不到已有的遗物，却能看到遗物效果，退出重进后又反过来；结算时网络重试，通关奖励发了两份；队友在层间传送门掉线，重连后被塞进另一个 run_id 的房间；每日挑战排行榜在日界前后各结算一次，同一人占了两个名次。roguelike_run_seed.py 的 RoguelikeRunSeed 管种子、随机序列、层快照、奖励和恢复。同一个 run_id 的随机数只能按固定序列消耗，宝箱、商店和敌人掉落共用这一条序列，重启或重连后接着走，不能重roll；奖励领取按 run_id、层数和宝箱ID幂等，重复领取返回 already_looted，重试要返回原奖励结果而不是再发一份；崩溃恢复要回到最近一次已提交的层快照，钥匙、遗物和血量都得对上，未提交的临时拾取要丢弃而不是补发；每日挑战种子按服务器日界生成，同一账号一天只能结算一次，日界切换时正在进行的 run 要允许打完但只结算一次。中途加入的队友要补齐当前层的遗物视图，但不能补发之前层数的奖励。每日挑战被刷成这样，先把种子、层快照和奖励结算串成一条线。

## 运行方式
```bash
python -m pytest tests -q
```
