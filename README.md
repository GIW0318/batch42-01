# GSB Bugfix Task
## 题面
会员中心把密码登录换成邮件链接后，客服接到登录失败和账号串号的投诉。链接里的令牌在页面渲染完之后才校验，邮箱安全网关提前抓取就把令牌消耗掉了；令牌没有绑定邮箱，拿到别人的链接换个账号也能进；有效期按客户端时间判断，把系统时间往前调就能续命；同一个令牌被两个标签页同时兑换，两边都拿到了会话；令牌明文存在数据库里，运维导一份表就能登录任意账号；重发链接时旧链接没有作废，几天前的邮件仍然可用；兑换成功后没有把令牌标记成已用，浏览器后退可以重放；链接里的跳转参数没有白名单，能被拿去做开放重定向；邮箱大小写和加号别名没有归一，同一个人被认成新用户；失败提示区分过期、不存在和已使用，可以拿来枚举；限流按来源地址统计，换代理就能继续刷；同一个令牌在移动端和网页端各兑换一次，两边都生成了独立会话。magic_link_redeemer.py 的 MagicLinkRedeemer 要把令牌做成一次性凭证，兑换和作废在同一个事务里完成，令牌只对签发时的邮箱有效，已用状态落盘并在重启后保留，失败一律返回同一种结果，跳转目标必须命中白名单，兑换请求按令牌编号幂等。test_magic_link_redeemer.py 的十五项检查今早重跑，仍然一条都过不了。

## 运行方式
```bash
python -m pytest tests -q
```
